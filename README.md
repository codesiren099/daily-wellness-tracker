# Daily Wellness Tracker

A simple HTML & CSS project that tracks daily health stats such as steps, calories, sleep, hydration and more.  
Built as part of the SnW individual project.

---

## Features
- Health Stats Section (steps, calories, sleep, meditation, etc.)
- Lifestyle Tiles (nutrition, fitness, wellness, calm, rest, hydration)
- Recent Activities List
- Weekly Table Snapshot
- Goals & Streak Section

---

## Tech Used
- HTML  
- CSS (Flexbox + Grid)  
- No frameworks, no JavaScript
